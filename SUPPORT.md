# Support

Use GitHub Discussions for setup questions, policy design, and usage examples
once Discussions is enabled. Use the bug report form for reproducible defects
and the feature form for a concrete unmet workflow.

Please do not report suspected vulnerabilities in public Issues. Follow
[SECURITY.md](SECURITY.md) instead.

Support is best-effort. Maintainers prioritize security problems, regressions,
and issues that affect multiple adopters. A minimal reproduction and the output
of `node --version` and `changeproof --version` make diagnosis much faster.
